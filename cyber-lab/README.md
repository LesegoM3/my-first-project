# Cybersecurity Lab 01 — Web Security Fundamentals

This is a safe, self-contained cybersecurity training lab.

## Objective

Learn to identify common web-security weaknesses without attacking a real system.

## Rules

- Test only this lab or systems you own/have explicit permission to test.
- Never enter real passwords, API keys, tokens, or personal information.
- The lab contains no real authentication backend and does not collect credentials.

## Challenge

Open `index.html` in a browser.

Your first mission is to inspect the page and identify three security weaknesses in the simulated application.

### Questions

1. Is the login process actually secure?
2. What information is exposed to the browser?
3. What could an attacker learn by inspecting the page's source/code?
4. Which weaknesses should be fixed first?

## Learning path

After you identify the weaknesses, we'll build the secure version together and explain why each fix works.

### Lab 01 skills

- Threat modeling
- Client-side vs server-side security
- Information exposure
- Basic secure authentication concepts
- Security logging and incident thinking

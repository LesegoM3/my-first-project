🔐 Secure Login Architecture Lab

This page now talks to the local training API. Never enter real credentials.

Login UI











What is happening?


    

  • The browser sends the username and password to /api/login.
    • 

  • The backend verifies the password against a salted PBKDF2 hash.
    • 

  • The backend returns a temporary token after successful authentication.
    • 

  • The token is kept only in this page's memory for the lab.
    • 

  • The /api/me endpoint checks that token before returning the authenticated user.
    • 

  • Successful and failed logins are written to the security event log.
    • 



Training account: lab-admin / training-only


The API must be running on your computer at http://127.0.0.1:5000. This is a lab, not production authentication.
